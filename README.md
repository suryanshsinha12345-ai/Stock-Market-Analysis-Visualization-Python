# Stock-Market-Analysis-Visualization-Python
Python-based stock market analysis using yfinance, Pandas, and Matplotlib, covering historical prices, data quality, resampling, financial ratios, revenue, EBIT, and financial statemen

## 📌 Project Overview

This project focuses on collecting, analyzing, resampling, and visualizing stock market data using Python.

The analysis uses the `yfinance`, `pandas`, `numpy`, and `matplotlib` libraries to work with historical market data and fundamental financial information for selected Indian stocks.

The project combines **technical/time-series data analysis** with **basic fundamental financial analysis** to demonstrate a structured Python-based stock market analysis workflow.

---

## 🎯 Objectives

The main objectives of this project are:

- Collect historical stock market data using Python
- Evaluate the quality of downloaded stock data
- Work with different historical periods and time intervals
- Visualize adjusted closing prices
- Resample minute-level stock data into hourly data
- Analyze key fundamental ratios
- Compare annual revenue and EBIT
- Explore financial statements
- Perform comparative analysis across selected companies

---

## 📊 Stocks Analyzed
